# Билеты по лабораторным

Подготовка к экзамену по 5 билетам (исходник — `Bilety_po_labam.pdf`), по одному `.txt` на билет:

1. `Билет_1_Отказоустойчивая_пара_DNS_BIND9.txt` — пара DNS BIND9 (Primary/Secondary, TSIG)
2. `Билет_2_Пользователи_и_PAM.txt` — useradd/groupadd/passwd, PAM (история паролей, словарь для root)
3. `Билет_3_Windows_Server_2025_DHCP_DNS_NAT.txt` — Windows Server 2025: DHCP, DNS, NAT без AD
4. `Билет_4_Samba_SELinux.txt` — Samba + SELinux
5. `Билет_5_NFS_autofs_репликация.txt` — NFS + autofs + репликация rsync/inotifywait
